二、复现步骤（Windows，Python 3.13 + 依赖见下）
----------------------------------------------------------------------

      （导出 PDF 还需要 LibreOffice Kit 的命令行：见 build_report.py 内 CLI 常量）

  # 1) 求解全部数值实验，写出 results.json（全量实测约 21 分钟；--quick 约 8 分钟）
  python 大作业\race_drift_solver.py
  python 大作业\race_drift_solver.py --quick      # 快速版（论文用全量）

  # 2) 重新生成插图（读取 results.json，约 1-2 分钟）
  python 大作业\build_figs.py

  # 3) 生成研究报告 docx，并导出 PDF
  python 大作业\build_report.py                   # 写 大作业_研究报告.docx
  #   PDF：用 LibreOffice Kit 转换（先把同名 pdf 删掉，否则报 EEXIST）
  #   node <...>\libreoffice-kit\lib\cli.js convert \
  #        --input 大作业_研究报告.docx --output 大作业_研究报告.pdf

  # 4) 生成答辩 PPT 与 PDF
  python 大作业\build_ppt.py

  # 5) 独立校验（与主模型实现无关的第二套代码；40 项检查全部通过）
  python 大作业\verify_reference.py

说明：build_report.py / build_ppt.py 中所有数字都从 results.json 与
verify/verification_report.json 读取，并做格式与数量自检（见
verify/report_number_check.json），因此改参数或换车型后可一键重生成。

三、交互演示 interactive_drift.html
----------------------------------------------------------------------
纯 HTML+CSS+JS 单文件，不依赖任何外网资源，双击即可打开。
  · 拖动 V（车速）与 δ（前轮转角）滑条：实时延拓跟踪抓地/漂移两条平衡点支路，
    显示 β、r、κ=f_x/(μ_r F_zr)、特征值与稳定/不稳定判定；
  · 面板 A：车辆俯视图 + 前/后轴轮胎力 + 摩擦圆（直观看到"驱动挤占侧向能力"）；
  · 面板 B：从任意初值出发的阻尼牛顿迭代动画（可单步、可调初值）；
  · 面板 C：抓地叶与漂移叶的平衡点分支图（稳定/不稳定分色，可点击载入工况）；
  · 面板 D：相平面 (β, r) 的向量场与 LQR 闭环/开环扰动轨迹；
  · 面板 E：世界坐标下的漂移轨迹（稳态漂移圆、车身姿态与侧偏角动画）。
  页面内置 4 个参考平衡点的自检（归一化残差 < 1e-6、特征值误差 < 1e-4），
  右上角徽章显示"自检通过"。

五、主要结论（数字均来自全量 results.json）
----------------------------------------------------------------------
  · 定速定转角下，除小转角抓地解外还存在一条"漂移叶"：β 显著为负、
    r 大、f_x 接近后轴摩擦圆上限；两叶在折叠点 δ_f(V) 处相撞并同时消失，
    δ_f 随车速单调下降（1.02 rad@6 m/s → 0.36 rad@30 m/s）。
  · 折叠（∂e/∂z 奇异）与动力学不稳定（∂f/∂x 有正实部）是两回事：
    漂移平衡点在多数工况为鞍点/不稳定结点，需闭环镇定。
  · 七种算法的收敛速度/耗时/成功率已定量比较：牛顿类 5 次迭代、约 0.4–0.5 ms；
    BFGS 需 14-26 次（中位 16 次）；LM/信赖域最稳健。
  · 设计优化（隐函数定理消元 + 增广拉格朗日）：在保证抓地侧向加速度 ≥1.366 g
    的前提下，把漂移所需摩擦圆利用率 κ 从 0.740 降到 0.518（降 30.0%），
    KKT 乘子 λ=0.139 与"约束右端减小 0.2 m/s² 时 κ* 下降 0.026"的影子价格吻合。
  · LQR 闭环：V=8/15/22 m/s 时闭环误差分别比开环小 1600/190/187 倍。
